# Design QA — локальное сравнение

Статическое браузерное приложение для сравнения двух вручную выбранных PNG/JPEG и локальных замечаний. Доступны наложение, разделитель, вид рядом, автоматическая подсветка отличий, пакетные и повторные проверки, черновики замечаний, HTML/PNG-отчёты, прямоугольные области на скриншоте сайта, заметки и JSON-экспорт.

Структура проекта:

```text
src/                    # приложение и проверки моделей
  app/
  pages/compare/
tests/
  e2e/                  # сценарии браузера
  fixtures/images/      # тестовые изображения
index.html
package.json
package-lock.json
tsconfig.json
vite.config.ts
vitest.config.ts
playwright.config.ts
infra/                  # необязательный Docker preview
```

Все команды выполняются из корня проекта. `npm test` запускает проверки моделей, `npm run test:browser` — все браузерные сценарии.

Нужны Node.js 24.21.0 и npm 11.19.0 (версии закреплены в репозитории).

```sh
npm ci
npm run dev
```

Vite покажет адрес локального приложения. `npm start` — синоним dev. Для production preview:

```sh
npm run build
npm run preview
```

Переменные окружения, backend и Docker не нужны. Сессия живёт только в памяти вкладки: перезагрузка закрывает изображения и замечания. JSON-экспорт содержит заметки и метаданные пары без изображений; восстановление из JSON не предусмотрено.

Проверки: `npm run typecheck`, `npm run lint`, `npm run build`, `npm run test:unit`, `npm run test:integration`, `npm run test:e2e`. Integration выбирает браузерные тесты с тегом `@integration`; E2E исключает их. Для браузерных проверок нужен Chromium Playwright (`npx playwright install chromium`).

Необязательный web-only Docker preview: `docker compose -f infra/compose.yml up --build -d web`, адрес http://127.0.0.1:58080. Подробности запуска — в [локальной настройке](docs/LOCAL_SETUP.md).

Требования: [PRD](docs/PRD.md), [TDD](docs/TDD.md). [Журнал](docs/IMPLEMENTATION_LOG.md) описывает реализованные возможности и проверки.

В режиме «Отличия» pixelmatch сравнивает изображения в исходном масштабе в фоновом потоке браузера. Ширины должны совпадать; высоты могут отличаться. Изображения выравниваются по верхнему левому краю, лишние строки целиком считаются отличиями. Доля отличий считается от площади более высокого изображения. Чувствительность и учёт сглаживания настраиваются; 100% чувствительности соответствует нулевому цветовому допуску. Сдвиг блока по вертикали подсвечивает и его прежнее, и новое положение. Файлы остаются на устройстве.

Рядом с подсветкой отображаются рамки автоматически найденных областей. Группировка объединяет соседние занятые ячейки 8 × 8 px, включая диагональные: это геометрические группы, а не распознавание элементов интерфейса. Границы рамок рассчитываются по реальным изменённым пикселям. «Предыдущее / следующее отличие» последовательно центрирует и приближает область; после последней области переход продолжается с первой. Фильтр шума по умолчанию скрывает группы меньше 12 изменённых пикселей, с возможностью отключения и выбора порога. Скрытые группы исключаются из подсветки и процента; число скрытых пикселей указано отдельно. Замена файлов или настроек сбрасывает выбор области.

В режиме «Отличия» кнопка «Исключить область» позволяет выделить прямоугольник на общем холсте, в том числе ниже края более короткого изображения. «Исключить выбранное отличие» добавляет рамку текущего найденного участка без рисования. Исключения отмечены серыми пунктирными рамками и перечислены с координатами; доступны приближение, удаление одной зоны и очистка всех. Допускается до 100 зон. Пересечения учитываются один раз, координаты округляются наружу до целых пикселей. Исключённая площадь вычитается из знаменателя процента и удаляется из маски до группировки и фильтрации шума. Если исключён весь холст, вместо процента выводится соответствующее сообщение. Зоны сохраняются при смене режима и параметров, сбрасываются при замене/очистке изображений и живут только в памяти вкладки; в JSON-экспорт замечаний не входят. Esc отменяет рисование, Space временно включает перемещение.

## Автоматизация без ИИ

- «Создать черновики замечаний» в режиме «Отличия» добавляет детерминированные описания найденных групп, координаты и фрагменты сайта/Figma. Повторный запуск пропускает одинаковые прямоугольники, общий лимит — 500 замечаний. Причина расхождения проверяется вручную; исходные фрагменты остаются привязаны к моменту создания замечания.
- «Повторная проверка» загружает новую версию сайта, сохраняя макет, исключения и замечания. Для каждой открытой области проверяются реальные пиксели отфильтрованной маски: совпадение, оставшиеся отличия либо «не проверено» для полностью исключённых/вышедших за границы областей. Статус OPEN/RESOLVED не меняется автоматически. На время проверки настройки заблокированы; их последующая смена сбрасывает отметки проверки. История содержит имя версии, время и счётчики; старые полноразмерные скриншоты не сохраняются.
- «Пакетная проверка страниц» сопоставляет уникальные имена без расширения и без учёта регистра. Пропущенные и неоднозначные имена показываются отдельно. До 20 пар обрабатываются последовательно; доступны отмена, ошибки отдельных пар, открытие пары и общий HTML-отчёт. Координатные исключения одиночной пары не переносятся на другие страницы. Результаты хранятся в памяти, при очистке освобождаются локальные URL.
- «Скачать HTML-отчёт» создаёт автономный файл со встроенными изображениями, координатами, настройками, исключениями, замечаниями и историей. Он не требует сервера или доступа к исходным blob-URL. В один отчёт включается до 100 пар фрагментов, а все координаты сохраняются независимо от этого лимита. «Скачать подсветку PNG» сохраняет общий холст с подсветкой и рамками в исходном масштабе.
- Прежний JSON-экспорт ручных замечаний сохраняет схему 1. Для автоматических/повторно проверенных замечаний используется схема 2 с происхождением, результатом проверки и исходными границами, когда они есть; изображения в JSON не включаются. Исторические области можно выгрузить после уменьшения высоты страницы.

Снимки, результаты пакета и история существуют только в памяти вкладки. Скачайте отчёт перед закрытием или перезагрузкой.
