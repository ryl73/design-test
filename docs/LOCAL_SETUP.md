# Локальный запуск

Используйте Node.js 24.21.0 и npm 11.19.0. При наличии nvm выполните `nvm use` в корне проекта.

```sh
npm ci
npm run dev
```

Все команды выполняются из корня. Исходники находятся в `src/`. `npm start` запускает тот же сервер разработки; Vite покажет адрес приложения. Переменные окружения и внешние сервисы не нужны.

## Просмотр сборки

```sh
npm run build
npm run preview -- --port 58080 --strictPort
```

Результат сборки находится в `dist/`.

## Проверки

- `npm run typecheck` — TypeScript.
- `npm run lint` — ESLint.
- `npm test` или `npm run test:unit` — проверки моделей.
- `npm run test:browser` — все браузерные сценарии.
- `npm run test:integration` — сценарии с тегом `@integration`.
- `npm run test:e2e` — остальные браузерные сценарии.

Playwright самостоятельно собирает приложение и запускает статический preview на 127.0.0.1:55310. Нужен установленный Chromium (`npx playwright install chromium`). Тестовые изображения находятся в `tests/fixtures/images/`. Эти проверки запускаются последовательно, поскольку используют один порт.

## Необязательный Docker preview

```sh
docker compose -f infra/compose.yml up --build -d web
```

Адрес: http://127.0.0.1:58080. Контейнер nginx раздаёт корневой `dist/`, проверка здоровья — HTTP GET главной страницы.

## Память сессии

Изображения, замечания, исключения, история и пакетные результаты хранятся в памяти вкладки. Перед перезагрузкой или закрытием скачайте отчёт. JSON содержит замечания и метаданные без изображений; HTML включает фрагменты и подсветку.
